# Reflective Paper Reader

基于唐·诺曼（Don Norman）的**反思性认知（Reflective Cognition）**、**心智模型（Mental Models）**与**行动双鸿沟（Gulf of Execution & Gulf of Evaluation）**理论，按照科研思路逆向还原 AI 论文作者的研究心路历程。

本 Skill 旨在打破被动接收信息的“体验性阅读（Experiential Reading）”，将排版精美、叙事线性的论文本身视为经过包装的**系统表象（System Image）**，通过慢速、主动的元认知推演，逆向还原作者真实的**科研心智模型（Research Mental Model）**。

## 适用范围

专注于计算机视觉（CV）、多模态大模型（MLLM）、具身智能（Embodied AI）与大语言模型（LLM）等 AI 领域论文精读。

## 理论映射：诺曼认知框架 × 科研思路逆向工程

| 诺曼认知理论概念 | 论文阅读中的传统误区（体验性认知） | 本 Skill 的逆向还原目标（反思性认知） |
| :--- | :--- | :--- |
| **系统表象 vs. 心智模型** (System Image vs. Mental Model) | 顺着章节顺序逐段翻译，把论文线性叙事当成作者真实的思考顺序 | 剥离修辞包装与造词，还原作者最初遇到的真实痛点、踩过的坑与破局直觉 |
| **执行鸿沟** (Gulf of Execution) | 只记住模型结构图和公式，不理解为什么这样设计 | 对比平庸备选方案（Naive Baselines），推演从核心直觉到具体架构的工程折中与隐含假设 |
| **评估鸿沟** (Gulf of Evaluation) | 只看主实验表格刷榜涨点（SOTA），全盘接受作者归因 | 审计消融实验闭环，剥离算力、数据规模、更强基座（Backbone）带来的混杂红利 |
| **反思层内化** (Reflective Level) | 读完合上论文只记住一个新缩写词，无法迁移到自己的课题 | 提炼可跨任务复用的科研方法论公式，顺着方法脆弱边界衍生具体 Follow-up 课题 |

## 使用方式

安装或复制本目录后，直接调用 `reflective-paper-reader`。完整执行指令位于 [SKILL.md](SKILL.md)；其中包含角色定义、模式路由、六大输出模块和领域专项审查规则。

## 快速触发示例

| 使用场景 | 推荐触发指令示例 |
| :--- | :--- |
| **全景逆向拆解（上传 PDF / 链接）** | `帮我用反思性认知精读这篇论文，还原作者从痛点到消融实验的完整科研思路。` |
| **苏格拉底分步伴读** | `我想精读这篇多模态/具身智能论文，请开启苏格拉底伴读模式，分步引导我推演作者的设计思路。` |
| **审稿与找 Idea 专项** | `用反思性认知拆解这篇论文的执行鸿沟与评估鸿沟，重点帮我做混杂红利审计，并推演 3 个 Follow-up 课题。` |
| **多篇论文范式对比** | `用反思性认知框架对比这两篇 VLA 论文在动作表征与训练范式上的核心取舍（Trade-offs）。` |
